# 修复资助受限资金核销服务

面向文物修复项目的受限资金管理服务，把**资助条款、预算版本、采购承诺、到货验收、材料实际用量、费用分摊**连成一条可追溯链路，使财务能在付款前逐笔判断每笔支出的合规来源。

典型问题：专项资助禁止支付进口材料，现场抢救却改用了进口加固剂，发票拆分计入三件器物，月底余额无法解释。本服务对该场景给出系统化答案。

## 业务规则（与需求逐条对应）

1. **付款前合规判定**：基金条款支持四个维度（材料产地、器物级别、支出类别、有效期），支持 `in / not_in / within` 操作符；承诺下单、发票核销、付款三个环节均校验，拒绝时回带条款原文依据。
2. **预算版本**：新版本总额取代旧版本；调减不得低于"承诺余量＋已核销净额"，即**调整只能影响尚未承诺的额度**。
3. **采购承诺**：下单即锁定预算额度；承诺余量按未交付数量×承诺日锁定汇率估值。
4. **到货验收**：未验收或验收数量不足不得核销；实际领用量不得超过验收合格数量。
5. **按用量自动分摊**：一张发票按"器物 × 材料"实际用量比例切分含税总额，尾差并入最大片，**各片合计恰好等于含税总额**。
6. **退料沿原分摊比例冲回**：生成负向凭证按原比例回到每件器物，余额沿原链路退回，**不产生无来源余额**；累计退料不得超过原领用。
7. **跨币种按业务日锁定汇率**：每张凭证记录所用汇率与本币金额，付款沿用发票业务日汇率，退料/反向冲销沿用原凭证汇率，事后汇率变动不重估。
8. **紧急采购**：可以 `pending_approval` 先占用待审额度、先验收核销；批准前禁止付款；**超过批准期限未获追认则承诺冻结、后续付款一律拒绝，并释放未交货部分的待审占用**。
9. **并发核销上限**：同一发票的累计净核销不得超过含税总额（线程锁保护）。
10. **期间结账**：已结账期间禁止补记任何凭证；结账后更正只能在当前期间出具**反向凭证**；先冲付款、再冲分摊。
11. **月底对账**：输出基金恒等式（预算 ＝ 承诺未核销 ＋ 已核销净额 ＋ 可用）、发票核销/已付明细、器物实际净消耗与账面分摊的逐件对齐，以及每笔被拒付款的错误码与条款依据。

## 目录结构

```
domain/contract.json        账务契约：凭证类型、条款维度、状态机、拒付错误码、汇率锁定规则
examples/
  funds.json                资助基金与限制条款（专项禁止进口材料）
  fx_rates.json             分日汇率表（每单位外币折人民币）
  artifacts.json            器物与级别
  budgets.json              预算版本
  commitments.json          采购承诺（含紧急待审承诺）
  invoices.json             发票（含税总额 + 材料明细行）
  receipts.json             到货验收
  usages.json               材料在器物上的实际用量
  allocations.json          原发票分摊样例
  run_scenario.py           端到端剧情演示
restricted_funds/           服务实现（仅 Python 标准库，Decimal 记账）
  terms.py                  条款模型与判定
  fx.py                     业务日锁定汇率
  models.py                器物/预算版本/承诺/发票/验收/用量
  ledger.py                只追加凭证台账 + 期间结账
  service.py               全部业务规则
  loaders.py               JSON 样例装配
  money.py                 金额舍入与按比例分摊
tools/validate_contract.py  契约与全套样例一致性校验
tests/test_rules.py         20 个规则单元测试
```

## 运行

```bash
python3 tools/validate_contract.py     # 样例数据一致性校验
python3 -m unittest discover -s tests  # 规则测试（20 项）
python3 examples/run_scenario.py       # 端到端剧情
```

剧情覆盖：进口材料误入专项被条款拒绝并改走一般经费 → 按用量分摊三件器物 →
含税总额并发上限 → 紧急采购待审期拒付 → 追认后按锁定汇率付款 →
预算调减被承诺挡住 → 退料沿 5:6:4 原比例冲回 →
另一笔紧急采购逾期冻结并释放占用 → 9 月结账、月底对账 →
10 月先红冲付款再红冲分摊。

## 凭证模型

凭证类型：`budget / commitment / invoice / allocation / return / payment / reversal`，
均记录原币金额、币种、业务日锁定汇率、本币金额与关联单据号。
凭证只追加、不可修改；反向凭证通过 `reverses` 关联原凭证，原凭证以 `reversed_by` 标记。

拒付错误码：`TERM_DENIED`、`BUDGET_EXCEEDED`、`COMMITMENT_NOT_APPROVED`、
`EMERGENCY_OVERDUE_FREEZE`、`RECEIPT_NOT_ACCEPTED`、`INVOICE_GROSS_EXCEEDED`、
`PERIOD_CLOSED`、`FX_RATE_MISSING`、`COMMITMENT_ADJUSTMENT_BLOCKED`、`REVERSAL_BLOCKED`，
每条拒付记录同时保存所违反的条款原文，供月底逐笔解释。
